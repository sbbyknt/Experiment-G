This is the code I used for numerical solutions for Experiment G from Practical Physics 1 2026-27.

- `Experiment_G_error_propagation.py` is the numerical solution to $\Delta g$ that is in my final solution
- `Experiment_G_correlated_variables.py` explores how $\Delta g$ would be smaller without the assumption that $I$, $M_p$ and $h$ are correlated. It is not intended as a rigorous demonstration, and as such the code relies on the `uncertainties` package
